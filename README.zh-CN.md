# Coder-yee Tap

[English](README.md) | 简体中文

[orok（一仓一钥）](https://github.com/coder-yee/one-repo-one-key) 为 GitHub 仓库管理独立 SSH 密钥。

## 如何安装？

```bash
brew install coder-yee/tap/orok
```

也可以先添加软件源，再安装：

```bash
brew tap coder-yee/tap
brew install orok
```

或者在 `brew bundle` 的 `Brewfile` 中添加：

```ruby
tap "coder-yee/tap"
brew "orok"
```

## 文档

orok 使用方法见[项目中文说明](https://github.com/coder-yee/one-repo-one-key/blob/main/README.zh-CN.md)。

Homebrew 使用方法可运行 `brew help`、`man brew`，或查看 [Homebrew 官方文档](https://docs.brew.sh)。
