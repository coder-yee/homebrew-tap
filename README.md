# Coder-yee Tap

English | [简体中文](README.zh-CN.md)

[orok (OneRepo OneKey)](https://github.com/coder-yee/one-repo-one-key) manages dedicated SSH keys for GitHub repositories.

## How do I install these formulae?

```bash
brew install coder-yee/tap/orok
```

Or add the tap first, then install:

```bash
brew tap coder-yee/tap
brew install orok
```

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "coder-yee/tap"
brew "orok"
```

## Documentation

For orok usage, see the [project documentation](https://github.com/coder-yee/one-repo-one-key#readme).

For Homebrew, use `brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
